# Hello World - Machine Learning Examples

This repository contains educational Jupyter notebooks demonstrating fundamental concepts in machine learning and data science. Created for teaching purposes, these notebooks provide hands-on examples with clear explanations and visualizations.

## 📚 Contents

### 1. Linear Regression Example (`linear_regression_example.ipynb`)
A comprehensive demonstration of linear regression using Python's popular data science libraries. This notebook covers:
- Generating synthetic data with noise
- Fitting linear regression models with scikit-learn
- Visualizing data and model fits
- Residual analysis and diagnostics
- Train/test split evaluation with metrics (MSE, R²)
- Statistical analysis with statsmodels (confidence intervals, prediction intervals)

**Key Libraries Used:** NumPy, Pandas, Matplotlib, Seaborn, scikit-learn, statsmodels

### 2. Sigmoid Function Demo (`sigmoid_demo.ipynb`)
A simple introduction to the sigmoid function, commonly used in logistic regression and neural networks. This notebook includes:
- Mathematical definition of the sigmoid function
- Visualization of the sigmoid curve
- Understanding its behavior and properties

**Key Libraries Used:** NumPy, Matplotlib

## 🚀 Getting Started

### Prerequisites
To run these notebooks, you'll need Python 3.x and the following packages:
```bash
pip install numpy pandas matplotlib seaborn scikit-learn statsmodels jupyter
```

### Running the Notebooks
1. Clone this repository:
   ```bash
   git clone https://github.com/ldbn74/hello-world.git
   cd hello-world
   ```

2. Start Jupyter Notebook:
   ```bash
   jupyter notebook
   ```

3. Open any notebook file (`.ipynb`) in your browser and run the cells sequentially.
